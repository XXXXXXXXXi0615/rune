# Lunartide Project Rules

## Read First

Before making any changes:

* Read all files inside /skills
* Review existing components before editing
* Reuse components whenever possible

## Project Identity

Lunartide is a mobile-first social platform.

Target style:

* iOS 26 inspired
* Liquid Glass
* Apple Music quality
* Instagram quality
* TikTok quality

Avoid:

* Enterprise dashboard UI
* Android Material Design
* Bootstrap aesthetics
* Generic AI-generated layouts

## UI Rules

* Use bottom capsule navigation
* Prioritize one-handed use
* Large touch targets
* Consistent spacing
* Rounded corners
* Soft blur and glass effects

## Development Rules

Before editing:

1. Scan existing code.
2. Reuse existing components.
3. Avoid duplicate CSS.
4. Avoid duplicate logic.

After editing:

1. Check mobile layouts.
2. Check dark mode.
3. Check responsive behavior.
4. Run lint if available.

## Review Checklist

For every screen:

* Does this feel like a real mobile app?
* Would Instagram ship this?
* Would TikTok ship this?
* Is it thumb-friendly?
* Is the design visually consistent?
